# NetSentinel

**Intelligent Network Intrusion Detection Through Anomaly Detection**

NetSentinel is an academic machine learning project exploring unsupervised anomaly detection techniques for identifying suspicious network traffic.

## Research Objectives

- Investigate unsupervised learning approaches for network intrusion detection.
- Extract and analyze network-flow features.
- Compare multiple anomaly detection algorithms.
- Evaluate models using precision, recall, F1-score, and PR-AUC.
- Develop an application for analyzing network traffic and identifying potential anomalies.

## Technologies

- Python
- Scikit-learn
- Pandas & NumPy
- FastAPI
- React & TypeScript
- Docker

## Dataset

The project uses the CICIDS2017 dataset developed by the Canadian Institute for Cybersecurity.
